# 📊 C로 직접 구현한 머신러닝 알고리즘

라이브러리 없이 **C 표준 라이브러리만으로** 대표적인 머신러닝 알고리즘 세 가지를 구현하고, 직접 만든 가상 데이터와 MNIST 손글씨로 실험했습니다.

| 알고리즘 | 분류 | 핵심 내용 |
|---|---|---|
| 선형 회귀 | 지도학습 (회귀) | 경사하강법과 정규방정식을 모두 구현해 비교 |
| KNN | 지도학습 (분류) | 결정 경계 시각화, 교차검증으로 k 선택, MNIST 92.2% |
| k-means | 비지도학습 (군집) | k-means++ 초기화, 엘보우 방법, 정답 없이 MNIST 묶기 |

scikit-learn에서 `fit()` 한 줄로 끝나는 일을 직접 구현하면서, 각 알고리즘이 **언제 잘 되고 언제 실패하는지**를 실험으로 확인하는 것이 목표였습니다.

## 실행 방법

필요한 것: C11 컴파일러(clang 또는 gcc), make

```bash
make               # 빌드
make run-data      # 1단계: 데이터 생성과 전처리 확인
make run-linreg    # 2단계: 선형 회귀
make run-knn       # 3단계: KNN (MNIST 필요)
make run-kmeans    # 4단계: k-means (MNIST 필요)
```

KNN과 k-means의 MNIST 실험에는 `data` 폴더에 MNIST 파일 4개가 필요합니다.

```bash
mkdir -p data && cd data
for f in train-images-idx3-ubyte train-labels-idx1-ubyte t10k-images-idx3-ubyte t10k-labels-idx1-ubyte; do
  curl -O https://raw.githubusercontent.com/golbin/TensorFlow-MNIST/master/mnist/data/$f.gz
done
gunzip *.gz && cd ..
```

(`data` 폴더가 없으면 옆에 있는 `../neural-net/data`를 자동으로 찾습니다.)

## 1. 데이터 준비

알고리즘을 검증하려면 **정답을 아는 데이터**가 필요합니다. 그래서 가상 데이터 생성기를 먼저 만들었습니다.

- `data_make_regression`: `y = X·w + b + 잡음` 으로 회귀 데이터 생성 (실제 w, b를 함께 반환)
- `data_make_blobs`: k개 중심 주변에 정규분포로 점을 흩뿌린 군집 데이터
- 정규분포 난수는 **박스-뮐러 변환**으로 직접 생성
- CSV 저장/불러오기, 학습·시험 분할, 표준화

표준화할 때 시험 데이터는 **학습 데이터의 평균·표준편차**로 변환해 데이터 누수를 막았습니다.

## 2. 선형 회귀

같은 문제를 두 방법으로 풀어 서로 검증했습니다.

```
            w1        w2        w3        b
실제값    -0.7247   -0.9049    2.6590    1.8872
경사하강  -0.7041   -0.9110    2.6583    1.8970
정규방정  -0.7041   -0.9110    2.6583    1.8970

시험 MSE 0.2123, RMSE 0.4607, R² 0.9714
```

두 방법의 결과가 소수점 넷째 자리까지 같고, MSE가 잡음의 분산(0.25) 수준이라 데이터에서 설명 가능한 부분은 거의 다 찾아냈습니다.

**정규방정식** `(AᵀA)θ = Aᵀy` 는 역행렬을 구하지 않고 **부분 피벗팅을 적용한 가우스 소거법**으로 풀었습니다. 역행렬 계산보다 빠르고 수치적으로 안정적입니다.

**학습률 실험**

```
학습률   50에폭 후 MSE
 0.001      11.0724     ← 너무 느림
 0.010       2.2701
 0.100       0.2473     ← 적당
 1.100   발산
```

**특징 수에 따른 속도** — 정규방정식은 약 d³, 경사하강법은 d에 비례

```
특징 수   정규방정식   경사하강법(100에폭)
    10       0.000초       0.001초
   100       0.008초       0.011초
   300       0.069초       0.040초
```

특징이 많아지면 순위가 뒤집힙니다. 특징이 수만 개인 문제(신경망 등)에 경사하강법을 쓰는 이유입니다.

## 3. KNN 분류

**k에 따른 결정 경계** — 화면의 모든 칸을 예측해 칠한 그림(소문자)과 학습 데이터(대문자)

- k = 1: 경계가 들쭉날쭉하고 다른 군집 안에 섬이 생김 (시험 73.3%) → 과적합
- k = 15: 경계가 매끄러워짐 (시험 80.0%)

**교차검증으로 k 고르기** (시험 데이터는 사용하지 않음)

```
   k   5겹 교차검증 정확도
   1    84.58%
  15    90.00%
  61    91.04%   ← 선택
 121    90.62%
```

**MNIST** (학습 1만 장, 시험 1천 장)

```
k = 1   정확도 92.00%
k = 3   정확도 92.20%
k = 5   정확도 91.40%
```

학습 과정 없이 "가장 비슷한 손글씨의 답을 따라가는 것"만으로 92%가 나옵니다.

구현 포인트
- 거리 비교에는 제곱 거리만 사용 (`sqrt` 생략해도 순서는 같음)
- 전체 정렬 대신 가장 가까운 k개만 유지하는 삽입 정렬 → 거의 O(n)
- 모델은 학습 데이터를 복사하지 않고 포인터로 참조

## 4. k-means 군집화

**초기화 비교** (군집 8개, 30번씩 실행)

```
방법        평균 관성   최악 관성   최선 대비 5% 이내
무작위        1462.2     3274.8    4 / 30번
k-means++     1248.2     1486.8    9 / 30번
```

무작위 초기화는 중심 두 개가 한 군집에 몰려 시작하면 나쁜 해(지역 최솟값)에 빠집니다. k-means++는 이미 고른 중심에서 먼 점일수록 잘 뽑히게 해(거리² 비례 룰렛 휠) 이를 크게 줄입니다.

**엘보우 방법** (실제 군집 5개)

```
 k    관성
 3    3117.8  (-64%)
 4    1196.9  (-62%)
 5     901.9  (-25%)
 6     833.1  (-8%)   ← 5 이후 감소폭이 급격히 작아짐
```

**MNIST를 정답 없이 10개로 묶기** (5천 장)

```
군집   가장 많은 숫자   순도
  5          0        94.7%
  2          2        90.7%
  1          6        85.1%
  0          7        34.5%   ← 4, 7, 9가 섞임
  7          8        36.2%   ← 3, 5, 8이 섞임

전체 순도 55.1%
```

0, 2, 6은 깔끔하게 묶였지만 4·7·9, 3·5·8은 픽셀이 비슷해 섞였습니다. 각 군집의 중심(평균 이미지)을 터미널에 그려 군집이 무엇을 학습했는지 확인할 수 있습니다.

## 세 방법 비교 (MNIST)

| | 정답 사용 | 학습 | 예측 (1장) | 결과 |
|---|---|---|---|---|
| 신경망 ([neural-net](../neural-net)) | 학습에 사용 | 2~3분 | 1ms 미만 | 정확도 97.76% |
| KNN | 예측 때 사용 | 없음 | 약 4ms | 정확도 92.2% |
| k-means | 사용 안 함 | 수 초 | - | 순도 55.1% |

KNN은 학습이 없는 대신 예측할 때 모든 계산을 하므로, 데이터가 늘수록 예측이 느려집니다. 신경망은 반대로 학습에 시간을 쓰고 예측은 빠릅니다.

## 배운 점

- 정답을 아는 가상 데이터로 알고리즘을 먼저 검증하는 방법
- 같은 문제를 두 가지 방법으로 풀어 서로 검증하기 (경사하강법 vs 정규방정식)
- 가우스 소거법과 부분 피벗팅, 알고리즘 복잡도(d³ vs n·d)에 따른 선택
- 과적합과 과소적합을 결정 경계로 직접 보기
- 교차검증으로 하이퍼파라미터를 고르고, 시험 데이터 누수를 피하는 법
- 초기값에 따라 결과가 달라지는 알고리즘(k-means)과 그 해결책
- 지도학습과 비지도학습의 차이를 같은 데이터(MNIST)로 비교
